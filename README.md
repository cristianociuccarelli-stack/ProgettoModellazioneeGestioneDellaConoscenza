# Accademia Arcana

Gioco di ruolo sviluppato in Java per il corso di Metodologie di Programmazione
(Università di Camerino, A.A. 2025/26).

Sei un nuovo studente dell'Accademia Arcana, sospesa su un arcipelago di isole
nel cielo. Scegli la tua affinità elementale, segui le lezioni, componi rune per
creare incantesimi, stringi legami con i compagni e affronti sfide magiche a turni
fino alla Prova dell'Equinozio di fine anno.

La documentazione completa del progetto è nella [Wiki](../../wiki) del repository.

## Requisiti

- JDK 21 o successivo

Gradle e JavaFX non vanno installati: vengono scaricati automaticamente.

## Compilazione ed esecuzione

```bash
./gradlew build
./gradlew run
```

Su Windows usare `gradlew.bat build` e `gradlew.bat run`.

## Uso di strumenti di intelligenza artificiale
